# docs/assets/agent-smith.svg

`docs/assets/agent-smith.svg` is a source SVG artwork file used as a branded wordmark for agent-smith.

## What it is

- A vector logo rendered as a grayscale block-letter mark spelling `SMITH`.
- Built from many small rounded rectangles rather than paths, giving it a pixel/tile aesthetic.
- Designed with a dark background and layered gray foreground tones.
- Includes an accessible `aria-label` describing the image as an agent-smith wordmark.

## Key facts

- File format: SVG
- Dimensions: `viewBox="0 0 402 90"`, rendered at `240x53`
- Visual style: monochrome, block-letter, pixel-inspired
- Role: reusable brand asset for UI, documentation, or headers

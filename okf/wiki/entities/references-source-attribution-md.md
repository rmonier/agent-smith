# References/source-attribution.md

`references/source-attribution.md` is a supporting work in the `skill-creator` repository that documents the conceptual lineage of `SKILL.md` and explains how the skill adapts prior art.

## Key Facts

- It is cited in `[[summaries/agents__skills__skill-creator__LICENSING-md]]` as the place where the skill's documented conceptual lineage is explained.
- The licensing file describes `SKILL.md` as original work overall while acknowledging that it incorporates ideas shaped by upstream `skill-creator` skills.

- This page functions as an attribution record rather than a user-facing skill guide.
- It helps distinguish [[concepts/attribution-based-reuse]] from the original authorship claims made for the skill package.

- It provides provenance context for reused or adapted material.

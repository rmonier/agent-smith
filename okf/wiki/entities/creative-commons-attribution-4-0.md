# Creative Commons Attribution 4.0

Creative Commons Attribution 4.0 International, often abbreviated `CC-BY-4.0`, is a permissive open-content license used for original documentation and other textual materials in this repository, including the README, `AGENTS.md`, and generated wiki and skill documentation where the project applies split licensing by file type.

## Key facts

- It governs original written material such as `README.md`, `AGENTS.md`, `SKILL.md`, and files under `references/` for the project skills.
- The repository README describes a split licensing model in which documentation is licensed under `CC-BY-4.0` while executable scripts are under Apache 2.0.
- The README also states that generated documentation and reporting artifacts are licensed consistently with the project's original prose unless otherwise noted.
- In the broader licensing scheme, it sits alongside Apache 2.0 code licensing and separate upstream licenses for vendored tools.
- The full license text is stored in `LICENSES/`.

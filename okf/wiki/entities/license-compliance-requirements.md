# License Compliance Requirements

License Compliance Requirements is the repository's licensing and attribution policy surface, covering how bundled license texts, notices, and third-party attributions are organized and maintained.

## Role in the repository

- Establishes the rules for using and distributing repository content under licensing compliance requirements
- Supports the presence of canonical license files such as `LICENSE`, `NOTICE`, and `THIRD_PARTY_NOTICES.md`
- Works alongside repository governance files like `REUSE.toml` and `LICENSING.md`
- Provides the legal framing for bundled assets, scripts, and documentation under the OpenKB source pack

## What the repository snapshot shows

- Multiple standard license texts are tracked, including Apache 2.0, CC BY 4.0, and MIT
- A dedicated `LicenseRef-All-Rights-Reserved.txt` file is present for non-open-content cases
- Third-party notice handling is explicit through `THIRD_PARTY_NOTICES.md`
- Licensing metadata is reinforced by `CITATION.cff` and other repository-wide governance files

## Why it matters

This entity matters because the repository is not only a documentation and tooling workspace; it also packages reusable content that must preserve provenance, attribution, and license compatibility. That makes licensing a core part of repository governance and [[concepts/attribution-based-reuse]].

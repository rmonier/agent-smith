# The Matrix

[[entities/the-matrix]] is the science-fiction franchise referenced in `README-md` as the source of the Agent Smith joke, the repository name, and the assimilation metaphor used to explain the project.

## Why it appears in this document

The README uses the franchise to frame `agent-smith` as a system that transforms repositories into an agent-ready state. It compares that transformation to Agent Smith's assimilation theme, but explicitly contrasts the project's behavior with coercion by emphasizing consent-first workflows.

## Key facts from the README

- The name `agent-smith` is presented as a playful reference to Agent Smith from [[entities/the-matrix]].
- The README treats assimilation as a metaphor for repository conversion into an agent-ready workspace.
- The joke is also described as the architecture: apply the system to a codebase and it comes out transformed.
- The text explicitly says the project asks for consent first, unlike the character it borrows from.
- The Matrix is invoked to support the repository's tone and naming, not as a technical dependency or implementation source.

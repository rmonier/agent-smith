# Google Cloud Platform

Google Cloud Platform is the organization associated with the `knowledge-catalog` repository that publishes the official Open Knowledge Format (OKF) v0.1 specification.

## Role in this document

The `okf-spec` document cites the OKF specification hosted in the GoogleCloudPlatform `knowledge-catalog` repository as the authoritative source for OKF v0.1. That makes Google Cloud Platform the named organization behind the spec’s publication context.

## Key facts

- The specification source is hosted at `github.com/GoogleCloudPlatform/knowledge-catalog`.
- The `okf/SPEC.md` file in that repository is described as the official OKF v0.1 specification.
- The spec emphasizes minimal, Markdown-based knowledge bundles with YAML frontmatter and permissive consumption behavior.
- The document positions OKF as a portable format for agents and humans, with conformance centered on required frontmatter fields.

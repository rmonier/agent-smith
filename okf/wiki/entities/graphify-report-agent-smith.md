# Graphify Report

`Graphify Report` is a structural analysis report for the OpenKB repository, generated by graphify and used as an exploration map for repository navigation and knowledge-base maintenance.

## Key facts
- It covers a corpus of 63 files and about 79,281 words.
- It reports a graph with 472 nodes, 550 edges, and 54 communities.
- Extraction quality is reported as fully extracted, with only one inferred edge and no ambiguous edges.
- The graph was built from commit `1bd19302`, so freshness depends on whether the repository has advanced since then.
- The report highlights hub pages such as `README.md`, `AGENTS.md`, `OpenKB lifecycle for OKF maintenance`, and `OpenKB repo build workflow`.

## What it is used for
- It helps identify cross-cutting structure in the repository.
- It surfaces weakly connected or isolated areas that may need documentation work.
- It supports [[concepts/graph-structure-analysis]], [[concepts/documentation-gaps]], and [[concepts/cross-community-bridges]].
- It functions as a navigation aid for [[concepts/knowledge-graph-analysis]] and repository orientation.

## Notable findings
- `main()` is the strongest bridge node in the graph.
- `bundle_key()` appears as an unexpected connector between build and skill-creation workflows.
- The report notes one inferred edge from `build_okf_source_pack.py` to `prune_okf_orphans.py`.
- No import cycles were detected.
- It identifies 234 isolated nodes and nine thin communities omitted from the main display.

# Apache License 2.0

This document is the full text of the [[concepts/apache-license-2-0]], a permissive open-source license that grants broad rights to use, modify, and distribute covered work.

## Key Terms

- Defines core legal terms such as `Work`, `Derivative Works`, `Contribution`, and `Contributor`.
- Grants a perpetual, worldwide, royalty-free copyright license for reproduction, modification, and distribution.
- Includes a patent license covering claims necessarily infringed by contributor submissions.
- Sets redistribution conditions, including preserving license text, marking modified files, and retaining notices.
- States that the license does not grant trademark rights except for reasonable descriptive use.

## Redistribution Requirements

- Distribute a copy of the license with the work or derivative work.
- Mark modified files as changed.
- Preserve relevant copyright, patent, trademark, and attribution notices in source distributions.
- Include `NOTICE` file attributions when the original work provides one, subject to the license's carve-outs.

## Warranty and Liability

- Provides the work on an `AS IS` basis with no warranties.
- Disclaims liability for damages arising from use or inability to use the work.
- Allows optional support, warranty, indemnity, or liability obligations when redistributing, but only on the redistributor's own behalf.

## Practical Meaning

- The license is designed to be permissive and business-friendly.
- It permits reuse in proprietary and open-source projects as long as attribution and notice requirements are respected.
- It is commonly used for software and documentation where broad adoption is desired.

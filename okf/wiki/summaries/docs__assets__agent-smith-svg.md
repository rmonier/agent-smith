# docs/assets/agent-smith.svg

This source file is an SVG wordmark asset for **agent-smith**, presenting the name `SMITH` as a grayscale, block-letter logo on a dark background.

## What it contains

- A compact vector logo sized for web use (`viewBox="0 0 402 90"`, rendered at `240x53`).
- An accessible `aria-label` describing the image as an agent-smith wordmark.
- A background rectangle in near-black, with the lettering built from many small rounded rectangles in varied gray tones.

## Design characteristics

- **Pixel/block aesthetic**: The letterforms are constructed from discrete square tiles rather than smooth paths.
- **Monochrome palette**: Uses layered gray shades for contrast and texture instead of color branding.
- **Logo-as-data**: The mark is embedded directly in SVG markup, making it resolution-independent and easy to reuse in interfaces.

## Notable implications

- The asset is suited for lightweight brand placement in UI, docs, or headers where a compact logo is useful.
- Its explicit `aria-label` suggests attention to accessible image semantics, even for decorative branding assets.
- The tile-based construction connects to ideas like [[concepts/accessibility-in-vector-assets]], [[concepts/brand-assets]], and [[concepts/svg-illustration-techniques]].

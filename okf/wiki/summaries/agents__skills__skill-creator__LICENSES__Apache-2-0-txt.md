# Apache License 2.0

This document is the full text of the [Apache License, Version 2.0](http://www.apache.org/licenses/), a permissive open-source license that allows use, modification, and redistribution under defined conditions.

## Key Terms

- Grants worldwide, non-exclusive, royalty-free rights to use, reproduce, modify, distribute, and sublicense the work.
- Extends a patent license from each contributor for claims necessarily infringed by their contributions.
- Requires redistribution to preserve the license text, copyright and attribution notices, and any applicable NOTICE file content.
- Allows modified works to carry additional or different license terms, as long as the original license conditions are still met.
- Includes standard disclaimers of warranty and limitation of liability.

## Notable Concepts

- [[concepts/permissive-open-source-licensing]]: The license is a classic permissive license, enabling broad reuse with minimal restrictions.
- [[concepts/license-conditions]]: It includes an explicit patent license, which is a defining feature of Apache 2.0.
- [[concepts/license-compliance-requirements]]: Redistribution is conditioned on preserving notices and including the license.
- [[concepts/open-source-attribution]]: NOTICE file handling is part of the license's attribution framework.

## Practical Implications

- Suitable for software projects that want broad adoption while preserving attribution and legal clarity.
- Compatible with downstream modification and commercial use.
- Places responsibility on redistributors to include required notices and avoid misrepresenting warranty or liability coverage.

## Context

This file is the canonical license text used by many projects to establish Apache 2.0 terms for source code and related materials.

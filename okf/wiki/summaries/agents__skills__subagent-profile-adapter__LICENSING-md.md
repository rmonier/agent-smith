# Licensing

This document defines the licensing terms for the `subagent-profile-adapter` skill. It separates the skill's content into two main license buckets: original documentation and assets under Creative Commons Attribution 4.0 International (`CC-BY-4.0`), and original executable files under `scripts/` under Apache License 2.0 (`Apache-2.0`).

## Key Points

- `SKILL.md`, original files under `references/` and `assets/`, and other original documentation are covered by `CC-BY-4.0`.
- Original executable files under `scripts/` are covered by `Apache-2.0`.
- Copyright is attributed to Romain Monier for 2026.
- The skill identifies `agent-smith` as the original source.
- Complete license texts are stored in `LICENSES/`.
- The skill states that it includes no third-party-derived material, so it does not need its own `THIRD_PARTY_NOTICES.md`.

## Notable Finding

- The skill uses a dual-license structure based on file type, which reduces ambiguity by assigning documentation and executable code different licensing regimes.

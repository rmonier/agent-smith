# Summary

This document defines the licensing split for `.agents/skills/skill-creator/LICENSING.md` and the related skill package materials. It distinguishes between Creative Commons licensing for the original documentation and Apache 2.0 licensing for executable scripts.

## Key Points

- `SKILL.md`, original files under `references/` and `assets/`, and other original documentation are licensed under [[concepts/creative-commons-attribution-4-0|CC-BY-4.0]].
- Original executable files under `scripts/` are licensed under [[concepts/apache-license-2-0|Apache-2.0]].
- `SKILL.md` is described as original work overall, while acknowledging conceptual lineage from upstream `skill-creator` skills.
- The document points to `references/source-attribution.md` for the conceptual lineage explanation.
- The exact borrowed passages, upstream sources, and copyright notices are recorded in `THIRD_PARTY_NOTICES.md`.
- Full license texts are stored under `LICENSES/`.
- The material is attributed to Romain Monier and the original source project `agent-smith`.

## Notable Ideas

- The project separates licensing by file type and function, which reduces ambiguity for downstream reuse.
- Attribution is treated as a first-class part of the repository structure through dedicated notice and source-attribution files.
- The document frames the skill as a largely original composition with limited adapted material from Apache-licensed upstream sources.
